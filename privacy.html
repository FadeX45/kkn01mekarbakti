Kebijakan Privasi — Buku Kas UMKM

Terakhir diperbarui: 26 Agustus 2026

Buku Kas UMKM adalah aplikasi pencatatan kas, piutang, dan hutang sederhana yang berjalan sepenuhnya di perangkat Anda (browser). Aplikasi ini dibuat untuk penggunaan pribadi/internal, bukan produk komersial.

Data apa yang disimpan?

Seluruh data transaksi (kas, piutang, hutang) yang Anda masukkan disimpan secara lokal di penyimpanan browser perangkat Anda (localStorage). Data ini tidak dikirim ke server pihak ketiga mana pun oleh aplikasi ini.

Fitur Cadangan Supabase (opsional)

Jika Anda memilih untuk mengatur dan menghubungkan project Supabase milik Anda sendiri lalu menggunakan fitur "Simpan ke Supabase", aplikasi akan mengirim data transaksi Anda ke database Supabase pada project tersebut, khusus untuk menyimpan satu cadangan data yang terhubung dengan akun (email) yang Anda buat.

  • Project URL, Anon Key, email, dan kata sandi yang Anda isi disimpan secara lokal di perangkat Anda (localStorage) agar tidak perlu diisi ulang; aplikasi ini tidak mengirimkannya ke pihak mana pun selain project Supabase Anda sendiri.
  • Dengan pengaturan kebijakan akses (Row Level Security) sesuai panduan dalam aplikasi, data cadangan hanya dapat diakses oleh akun yang Anda buat sendiri di project Supabase tersebut.
  • Data yang disimpan ke Supabase sama persis dengan data yang Anda masukkan sendiri ke aplikasi (kas, piutang, hutang).
  • Aplikasi tidak membagikan data Anda kepada pihak ketiga mana pun di luar project Supabase yang Anda kelola sendiri.
  • Anda dapat menghapus data cadangan atau seluruh project Supabase kapan saja melalui dasbor Supabase Anda, dan dapat memutus koneksi di perangkat ini melalui tombol "Keluar" pada aplikasi.

Kontak

Jika ada pertanyaan mengenai kebijakan privasi ini, silakan hubungi pengembang aplikasi melalui akun GitHub tempat aplikasi ini dipublikasikan.
