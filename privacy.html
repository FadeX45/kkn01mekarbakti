Kebijakan Privasi — Buku Kas UMKM

Terakhir diperbarui: 26 Agustus 2026

Buku Kas UMKM adalah aplikasi pencatatan kas, piutang, dan hutang sederhana yang berjalan sepenuhnya di perangkat Anda (browser). Aplikasi ini dibuat untuk penggunaan pribadi/internal, bukan produk komersial.

Data apa yang disimpan?

Seluruh data transaksi (kas, piutang, hutang) yang Anda masukkan disimpan secara lokal di penyimpanan browser perangkat Anda (localStorage). Data ini tidak dikirim ke server pihak ketiga mana pun oleh aplikasi ini.

Fitur Cadangan Google Drive (opsional)

Jika Anda memilih untuk menghubungkan akun Google dan menggunakan fitur "Simpan ke Google Drive", aplikasi akan meminta izin akses terbatas ke folder data aplikasi tersembunyi (App Data Folder) di akun Google Drive Anda sendiri, khusus untuk menyimpan satu file cadangan data transaksi Anda.

  • Aplikasi hanya dapat membaca/menulis file cadangannya sendiri di App Data Folder — tidak dapat mengakses file atau folder lain di Google Drive Anda.
  • Data yang disimpan ke Google Drive sama persis dengan data yang Anda masukkan sendiri ke aplikasi (kas, piutang, hutang).
  • Aplikasi tidak membagikan data Anda kepada pihak ketiga mana pun.
  • Anda dapat memutus akses ini kapan saja melalui halaman Google Account → Security → Third-party access.

Kontak

Jika ada pertanyaan mengenai kebijakan privasi ini, silakan hubungi pengembang aplikasi melalui akun GitHub tempat aplikasi ini dipublikasikan.
